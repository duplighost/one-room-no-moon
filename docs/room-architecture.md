# Phase 8 — Room Architecture (floorplans + true elevation)

Decided with the user (2026-06-13): build floorplans **and** elevation together,
with **true high-ground** line-of-fire. The point is to kill "sterile, open,
rectangular" rooms by giving them real architecture and verticality — without
reintroducing the reachability mess that plagued big No Moon. The defense against
that mess is the same as everywhere else in this project: **invariants proven
headlessly** (connectivity + line-of-fire) before merge.

Everything here reuses the existing rect/circle collision. The genuinely new work
is (a) a macro-generation pass that lays walls with guaranteed openings, (b) a
`level` integer on entities/bullets/hazards, and (c) raised rendering.

## 1. Wall vocabulary

Obstacles gain two structural kinds beyond cover:
- **wall** — thick solid rect. Blocks movement and *all* bullets
  (`ledgeHeight: Infinity`). Drawn with depth (face + cap shadow), biome-styled.
- **ledge** — the perimeter of a raised tier. Blocks movement always; blocks a
  bullet only if `bullet.level < ledgeHeight`. Drawn as a raised lip.
- Some wall spans are **breakable segments** (`species:'wallSegment'`, hp scales
  with depth); breaking one opens a *wide* passage (the whole segment clears, not
  a keyhole) — this is the "break parts to open the room" idea.

Collision is unchanged for movement (walls/ledges are rects). Bullets get a
height check (§4).

## 2. Floorplans (Layer 1)

A `floorplan` axis rolled per room (no-repeat bag, like biome/layout). Runs
*before* the cover scatter; the cover scatter then fills chambers lightly.
Rooms with a floorplan are larger (so nothing feels cramped) and all openings are
generous (≥ ~3 player diameters).

Archetypes:
- **bisect** — one wall splitting the room in two; joined by a wide gap *or* a
  breakable segment.
- **innerSanctum** — a room-within-the-room (walled box) with 1–2 entrances;
  holds a cache / reward / the meanest enemies.
- **spineCorridor** — parallel walls forming a central hallway with side alcoves.
- **quadrants** — a cross of walls, four chambers, gaps at the hub.
- **none** — open room (the current behavior stays in the bag so not every room
  is partitioned).

### Connectivity invariant (the anti-mess rule)
Generated by construction: every partition has at least one wide gap OR a
breakable segment — never fully sealed. Then validate: coarse-grid flood-fill
from the player spawn must reach the portal cell and every spawn/event cell
(treating breakable segments as passable, since the player can open them). If a
content cell is unreachable, punch a gap or re-roll the floorplan. `oneRoomDebug`
gets a reachability report; a headless test asserts connectivity over ≥300
generated rooms across all biomes/rounds.

## 3. Elevation: tiers (Layer 2)

A **tier** is a raised sub-region: `{ rect, height, ramps:[…] }` with `height`
1 (ground is 0; allow 2 later). Mechanically a tier is a walled enclosure (its
perimeter is **ledge** obstacles) with **ramp** gaps you walk through to get
on/off. So movement reuses Layer-1 enclosure tech exactly.

- `level` of an entity = height of the tier whose rect contains it, else 0.
  Recomputed after movement each frame. Because ledges block all non-ramp
  crossing, level only changes when you walk a ramp — no teleporting levels.
- **Rendering:** tier floor drawn raised (lighter tint + lip + drop shadow);
  entities with `level>0` drawn with a small upward pixel offset and sorted above
  ground entities, so it reads as "up there." Collision stays in logical 2D.
- Reachability: every tier must have ≥1 ramp, and the ground around it stays
  connected (validated by the same flood-fill, with ramps as passable).

## 4. True high-ground (Layer 3)

`level` is the whole model. Bullets carry `bullet.level` = shooter's level at
spawn (fixed for the bullet's life — "fired from up here / down there").

Two rules, and they compose cleanly:
1. **Ledge height-gating (movement of bullets):** a bullet collides with a ledge
   iff `bullet.level < ledge.ledgeHeight`. So a ground shot (level 0) is walled
   out of a platform (it splats on the cliff); a platform shot (level 1) flies
   over ledges of height ≤1.
2. **Hit gate:** a bullet damages a target iff `bullet.level >= target.level`.
   (The ledge rule already makes the illegal cases physically impossible; this is
   the backstop.)

Consequences (the intended fantasy, and it cuts both ways):
- You on the ground **cannot** hit a sniper on a platform — climb the ramp.
- The sniper on the platform **rains down** on you (its level-1 shots clear the
  ledge and the hit gate passes for your level 0).
- Up on the platform you're **safe from ground shooters** and can trade with the
  platform's occupants on equal footing.
- Contact damage is naturally same-level (ledges block cross-level movement).
- **Hazards** carry a level; they only harm a player on the same level.
- **Auto-aim** filters to targets you can legally hit (`e.level <= p.level`), so
  the game never locks you onto a sniper you can't reach from the ground — which
  also teaches the rule wordlessly.

### Line-of-fire invariant
Headless test asserts: a level-0 bullet fired at a level-1 enemy never deals
damage (blocked); a level-1 bullet fired at a level-0 enemy does; same-level
hits work; an enemy bullet from the ground never hurts a platform player.

## 5. Data model deltas

```
room.floorplanId         // 'bisect' | 'innerSanctum' | 'spineCorridor' | 'quadrants' | null
room.tiers: [{ rect:{x,y,w,h}, height, ramps:[{side,pos,span}] }]
obstacle.wall            // true → solid structural wall
obstacle.ledgeHeight     // bullet passes if bullet.level >= this (Infinity for walls)
obstacle.species='wallSegment'  // breakable wall → opens a wide passage
entity.level             // player + enemies; 0 = ground
bullet.level             // = shooter.level at spawn
hazard.level             // = levelAt(spawn)
```

New helpers: `levelAt(room,x,y)`, flood-fill `reachable(room)`.

## 6. Build order (commit per layer, each green + screenshotted)

1. **8a Floorplans** — wall vocabulary, 4 archetypes + none, bigger rooms, wide
   openings, breakable wall segments, connectivity flood-fill + audit + test.
2. **8b Tiers (movement + render)** — tier regions, ledges, ramps, `level`
   tracking, raised rendering + sort, ramp/reachability validation.
3. **8c High-ground combat** — `bullet.level`, ledge height-gating, hit gate,
   hazard level, auto-aim filter; line-of-fire test.
4. **8d Integration** — roll floorplan/tier as roller axes (no-repeat), director
   places spawns in reachable chambers and seeds platform occupants (snipers/
   turrets love high ground), tune sizes, full visual pass desktop + mobile.

## 7. Risks & mitigations
- **Softlock / unclearable** → connectivity by construction + flood-fill audit
  (≥300 rooms) as a merge gate.
- **Cross-level confusion** → auto-aim filter + raised rendering + the sniper
  raining down teach the rule without text.
- **Perf** (more rects) → walls are cheap rects; baked background unaffected;
  watch obstacle count, keep within existing caps.
- **Spawn-on-wall / spawn boxed-in** → spawn placement validates chamber + level
  reachability, same as obstacle-avoidance does today.
